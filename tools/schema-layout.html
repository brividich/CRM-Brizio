Eccezione: l'area Admin
Le pagine dell'Admin Portale (e Hub Tools) sovrascrivono il blocco subnav:
{% block subnav %}{% include "admin_portale/components/admin_subnav.html" %}{% endblock %}

L'admin_subnav.html è hardcoded — non passa per il Navigation Registry. È un componente statico che risolve le URL con {% url %} e gestisce lo stato attivo confrontando request.resolver_match.view_name.

I moduli operativi (assenze, anomalie, hub_tools…) usano invece il subnav dinamico alimentato dal Navigation Builder.
