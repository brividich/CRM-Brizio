Logo Menu Anomalie
Sostituisce il logo al centro della pagina menu. Il logo viene mostrato senza sfondo — usa un file PNG con sfondo trasparente.
Requisiti immagine
  • Formato consigliato: PNG con sfondo trasparente (alpha channel)
  • Risoluzione consigliata: 1000 × 260 px (ratio ~3.8:1)
  • Dimensione massima file: 2 MB
  • Formati accettati: PNG, JPG, JPEG, SVG, WebP, GIF
  • Nota: JPG e WebP non supportano la trasparenza — potrebbe apparire un rettangolo bianco dietro al logo

Template Report OP
Carica un template HTML personalizzato usato per generare il report riepilogativo del documento OP con tutte le anomalie collegate. Se non è presente un template personalizzato, viene usato quello di default del sistema.
Linee guida per il template
  • Il file deve essere un .html valido in codifica UTF-8, max 512 KB.
  • Usa la sintassi Django Template: i dati dell'OP sono in {{ op.campo }} e le anomalie sono disponibili con {% for anomalia in anomalie %} ... {% endfor %}.
  • Placeholder obbligatori (devono comparire nel file): {{ op.id }}, {{ anomalia.seriale }}, {{ anomalia.descrizione }}.
  • Campi utili: op.pn, op.capo, op.car, report.anomalie_totali, report.allegati_totali, anomalia.avanzamento, anomalia.note_capocommessa, anomalia.numero_rdc.
  • Per ogni anomalia puoi anche iterare anomalia.attachments per mostrare nome, dimensione e metadati degli allegati nel report OP.
  • La lista allegati è in {{ allegati }} (lista di nomi file).
  • Non sono permessi tag <script src="https://..."> verso domini esterni.
  • Scarica il template di default come punto di partenza: report_default_op.html (apri un report valido con /api/anomalie/report?op_item_id=ITEM_ID oppure /api/anomalie/report?op_id=OP/2026/123).
