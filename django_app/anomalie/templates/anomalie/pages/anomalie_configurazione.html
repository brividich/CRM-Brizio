Logo Menu Anomalie
Sostituisce il logo al centro della pagina menu. Usa PNG con sfondo trasparente.
Requisiti immagine
  • Formato consigliato: PNG con sfondo trasparente (alpha channel)
  • Risoluzione consigliata: 1000 × 260 px (ratio ~3.8:1)
  • Dimensione massima file: 2 MB
  • Formati accettati: PNG, JPG, JPEG, SVG, WebP, GIF
  • Nota: JPG e WebP non supportano la trasparenza — potrebbe apparire un rettangolo bianco dietro al logo

Template Report OP
Template HTML personalizzato per il report riepilogativo OP con tutte le anomalie collegate.
Linee guida per il template
  • Il file deve essere un .html valido in codifica UTF-8, max 512 KB.
  • Usa la sintassi Django Template: dati dell'OP in {{ op.campo }} e anomalie con {% for anomalia in anomalie %} ... {% endfor %}.
  • Placeholder obbligatori: {{ op.id }}, {{ anomalia.seriale }}, {{ anomalia.descrizione }}.
  • Campi utili: op.pn, op.capo, op.car, report.anomalie_totali, anomalia.avanzamento, anomalia.note_capocommessa, anomalia.numero_rdc.
  • Per ogni anomalia puoi iterare anomalia.attachments per allegati.
  • La lista allegati è in {{ allegati }}.
  • Non sono permessi tag <script src="https://..."> verso domini esterni.
  • Scarica il template di default: report_default_op.html
